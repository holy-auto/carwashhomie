# Googleアナリティクス（GA4）× サーチコンソール 連携手順

サイト側のコード（GA4タグ・サーチコンソール認証メタタグ）は実装済みです。
以下は **Googleの管理画面と Vercel で行う作業** です。所要時間は30分ほど。

```
① GA4プロパティ作成 → ② 測定IDをVercelに設定 → ③ サーチコンソールで所有権確認
→ ④ サイトマップ送信 → ⑤ GA4とサーチコンソールをリンク → ⑥ レポートを公開
```

---

## ① GA4 プロパティを作る

1. https://analytics.google.com を開く（info@holy-auto.com などお店で管理するGoogleアカウントで）
2. 左下の **管理（歯車）** → **作成** → **プロパティ**
3. プロパティ名：`Car Wash Homies`、タイムゾーン：**日本**、通貨：**日本円**
4. ビジネス情報を入力して作成
5. **データストリーム** → **ウェブ** → URL に `carwashhomies.com` を入力
   - 「拡張計測機能」は **ON のまま**（ページ遷移・スクロール・外部リンククリック等が自動で計測されます）
6. 表示された **測定ID（`G-` で始まる）** を控える

## ② 測定IDを Vercel に設定

1. Vercel → プロジェクト → **Settings → Environment Variables**
2. 追加：
   | Key | Value | Environment |
   |---|---|---|
   | `NEXT_PUBLIC_GA_ID` | `G-XXXXXXXXXX` | Production のみ推奨 |
3. **Redeploy**（`NEXT_PUBLIC_*` はビルド時に埋め込まれるため再デプロイ必須）
4. サイトを開いて GA4 → **レポート → リアルタイム** に自分のアクセスが出れば成功

> Preview 環境にも入れるとテスト閲覧がカウントされます。本番のみがおすすめ。
> `/admin`（管理画面）ではタグを出さないようにしてあります。

## ③ サーチコンソールで所有権を確認

https://search.google.com/search-console → **プロパティを追加**。方法は2つ：

### A. ドメインプロパティ（おすすめ）
- `carwashhomies.com` を入力 → 表示される **TXTレコード** をDNS（Vercel / お名前.com 等）に追加 → 確認
- `www` あり/なし・http/https をまとめて計測できる。コード側の設定は不要

### B. URLプレフィックス（HTMLタグ）
- `https://carwashhomies.com` を入力 → 確認方法で **HTMLタグ** を選ぶ
- `<meta name="google-site-verification" content="abc123..." />` の **`content` の中身だけ** をコピー
- Vercel に環境変数 `GOOGLE_SITE_VERIFICATION=abc123...` を追加 → 再デプロイ → 「確認」

> ①で使ったのと同じGoogleアカウントに **GA4プロパティの編集者以上** と **サーチコンソールの所有者** の両方の権限が必要です（⑤のリンクに必要）。

## ④ サイトマップを送信

サーチコンソール → **サイトマップ** → `sitemap.xml` と入力して送信。
（`https://carwashhomies.com/sitemap.xml` は自動生成済み）

## ⑤ GA4 とサーチコンソールをリンク

1. GA4 → **管理** → 「サービス間のリンク設定」の **Search Console のリンク**
2. **リンク** → **アカウントを選択** → ③のプロパティ（`carwashhomies.com`）を選ぶ
3. **ウェブストリームを選択** → ①で作った `carwashhomies.com` のストリーム
4. 確認して **送信**

## ⑥ レポートをメニューに表示

リンクしただけでは左メニューにレポートが出ません。

1. GA4 → **レポート** → 下部の **ライブラリ**
2. コレクション「**Search Console**」の **︙ → 公開**
3. 左メニュー「レポート」に **Search Console → クエリ / Google オーガニック検索トラフィック** が出現

| レポート | わかること |
|---|---|
| クエリ | どんな検索語で表示・クリックされたか（表示回数・CTR・平均掲載順位） |
| Google オーガニック検索トラフィック | 検索から来た人がどのページに着地し、その後どう行動したか（エンゲージメント・予約ページ到達など） |

> データはリンク後から反映（サーチコンソール側は過去16か月分を参照可）。反映まで1〜2日かかることがあります。

## おすすめの追加設定（任意）

- **キーイベント（旧コンバージョン）**：予約・問い合わせの計測
  - GA4 → 管理 → イベント → 送信完了ページの `page_view` などからイベントを作成し「キーイベントとしてマーク」
- **データ保持期間**：管理 → データの収集と修正 → データ保持 → **14か月** に変更（初期値は2か月）
- **内部トラフィック除外**：管理 → データストリーム → タグ設定 → 内部トラフィックの定義 で店舗のIPを除外

## コード側の実装（参考）

| ファイル | 内容 |
|---|---|
| `components/GoogleAnalytics.tsx` | gtag.js を読み込み。`NEXT_PUBLIC_GA_ID` 未設定なら何も出力しない |
| `app/layout.tsx` | 上記を公開ページに配置（`/admin` は除外）、`GOOGLE_SITE_VERIFICATION` があれば認証メタタグを出力 |
| `components/PrivacyPolicy.tsx` | 「Cookie・アクセス解析」にGoogleアナリティクス利用・オプトアウト方法を明記（GA利用規約で必須） |
